填写参数

持仓基准

填写市场、股票代码和名称、目前持有股数、每股成本、目前股价及每手股数。股价用于估算当前盈亏和回本距离；它本身不会改变持仓资金回本成本。

买入与卖出计划

输入计划价格、股数和该侧交易费用。没有某一侧交易时，将该侧股数设为 0，该侧费用便不会计入。卖出股数不能超过当前持仓，交易后股数必须大于零才能计算回本成本。

所有结果都是按你填写的参数进行的计划测算。实际成交价格、成交股数、费用和证券交易规则以券商及市场为准。

看懂结果

结果项目含义
资金回本成本把原持仓成本、卖出净所得和买入总支出合并后，交易后每股需要收回的资金。
本次买卖净现金流卖出净所得减去买入总支出；显示净收回或净投入，不代表整笔持仓盈利。
回本成本演变依次查看当前、卖出后及买入后的成本变化。低于成本卖出后，剩余持仓的回本成本可能上升。
目标成本反推估算达到目标回本成本所需买入股数、整手数量及预计资金；这是数学测算，不是交易建议。
买入方案比较不同手数（美股为不同股数）的预计支出和新回本成本，可应用某个方案继续测算。
总体盈亏与回本距离按当前股价估算计划完成后的状态，不是已实现盈亏或未来收益预测。

资金回本成本的计算口径为：

（原持仓总成本 − 卖出净所得 + 买入总支出）÷ 交易后股数

该口径会体现卖出已实现盈亏的影响，因此可能与券商按成交批次展示的账面平均成本不同。

设置交易费用

在交易参数区打开费用设置，可选择手动填写或自动估算。

手动填写

按券商预估单或历史成交单，分别填写本次买入、卖出的实际总费用（包括适用佣金和税费）。适用于需要贴近自己账户收费方式的测算。

自动估算

可配置页面提供的市场费用预设和相关费率。自动估算只是近似值，不同券商、证券类型、最低收费、舍入方式及监管规则会造成差异。请用券商成交单核对；A 股暂不提供自动费用估算。

默认的费用预设不保证反映最新或你的专属收费规则。汇率和未录入的其他费用不包含在结果内；重要决策前请核对券商费用。

保存、比较与分享

持仓簿与方案

将测算加入持仓簿后，参数、费用、方案和已确认的加仓记录保存在当前浏览器。用本股方案保存 A / B 两组参数，可比较回本成本、资金流、持仓和费用。

备份与换设备

持仓数据默认保存在本机浏览器，不会自动同步到其他设备。请定期从持仓簿导出 JSON 文件并妥善保存。换设备时，在新设备导入备份即可继续使用。

导入 JSON 会替换当前浏览器中的持仓簿、当前测算、方案和费用设置。导入前先导出当前数据，以免覆盖后无法找回。

分享测算

顶部更多菜单提供分享和复制结果。分享链接会包含当前测算参数，方便对方打开同一组输入；界面说明链接不含账户或身份信息。请勿在链接参数中填写不希望公开的内容。

不同市场的注意事项

市场填写与核对
港股按证券实际每手股数填写；不同股票可能不同。自动费用为估算，印花税适用情况及收费以券商成交单为准。
A 股默认每手 100 股，但应按证券规则调整。费用请手动填写券商实际总费用；工具不校验 T+1 规则或实际可卖数量。
美股按股数填写，方案对比使用不同股数档位。自动预设可能未覆盖 ADR、平台费或券商特殊收费，请按成交单核对。

不同市场的计价货币可能不同，本工具不会自动换汇。请在同一市场、同一计价货币下比较结果。

常见问题

为什么回本成本和券商显示不同？

本工具按资金回本口径计入卖出净所得对待收回资金的影响；券商可能按持仓批次或自己的成本口径展示。请先核对双方的费用、股数和成本口径。

为什么卖出后成本反而上升？

如果卖出价格低于原成本，已实现亏损需要由剩余持仓收回，剩余每股对应的回本成本可能因此升高。

为什么换浏览器后看不到持仓？

数据保存在原浏览器本机，不会自动云同步。请从原设备导出 JSON，再在新设备导入。

可以直接按计算结果下单吗？

测算只反映输入假设，不会检查账户资金、市场规则、实际可成交数量或风险承受能力。下单前请自行核实。

风险提示：CostBuddy 仅提供个人持仓情景测算，不构成投资建议、收益承诺或买卖信号。市场价格和费用可能变化，投资决策及其后果由使用者自行承担。
