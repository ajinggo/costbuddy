1. 产品用途

costbuddy 用于测算港股持仓在计划卖出、继续买入以及计入交易费用后的资金回本成本。

它可以帮助试用者快速回答以下问题：

  • 卖出部分持仓后，剩余股票需要涨到多少才能收回全部资金？
  • 在某个价格继续买入后，新的资金回本成本是多少？
  • 本次买卖会净收回资金，还是需要追加投入？
  • 如果希望把回本成本降到目标价格，大约需要买入多少股、多少手？
  • 买入 1 至 5 手时，各方案需要投入多少资金，成本分别是多少？
  • 如何保存多只股票，并在其他电脑继续测算？
本工具计算的是包含已实现卖出盈亏影响的“资金回本成本”，可能与券商 App 按成交批次显示的账面平均成本不同。

2. 试用前准备

建议提前准备以下数据：

数据填写说明
股票代码例如 00700；纯数字代码会自动补足为 5 位
股票名称可选，用于持仓簿中识别股票
目前股数交易前实际持有的股票数量
目前成本当前每股持仓成本，单位为 HKD
目前股价用于估算当前总体盈亏和距离回本的幅度
每手股数请以该证券实际每手股数为准
买入计划计划买入价格、股数和费用
卖出计划计划卖出价格、股数和费用
目标成本希望达到的每股资金回本成本

推荐使用电脑端浏览器。页面采用一屏三列工作台设计，窗口较小时会自动适配缩放。

3. 页面结构

3.1 顶部操作区

顶部提供以下操作：

  • 持仓簿：查看和管理已保存的多只股票
  • 新建测算：清空当前股票参数，开始下一只股票的计算
  • 本股方案：保存方案 A / B 并进行对比
  • 分享：复制包含当前测算参数的分享链接
  • 复制结果：复制当前完整测算结果
  • 恢复示例：恢复内置试用数据，需要在 3 秒内再次点击确认

3.2 交易参数区

页面左侧用于录入：

  1. 持仓基准
  2. 买入计划
  3. 卖出计划
  4. 手动或自动费用设置

修改任意有效参数后，右侧结果会实时更新，无需点击“计算”。

3.3 结果工作区

结果区域主要包括：

  • 资金回本成本：完成计划交易后的核心结果
  • 本次买卖净现金流：卖出净所得减去买入总支出
  • 交易结果摘要：交易后持仓、待收回总成本、总体盈亏和回本距离
  • 回本成本演变：按交易前、卖出后、买入后的顺序展示成本变化
  • 目标成本反推：计算达到目标所需的理论股数和最少整手方案
  • 1 至 5 手买入方案：比较不同手数的投入和新成本
  • 目前股价与回本价：对比市场价格和资金回本价格
  • 资金明细：拆分原始成本、卖出净收回、买入总支出和手续费
  • 买入价与回本成本：观察买入价格变化对新回本成本的影响

4. 三分钟快速试用

第一步：打开网站

访问：

https://costbuddy.space

网页无需安装、注册或登录。

第二步：恢复内置示例

如果页面数据已被修改：

  1. 点击右上角的“恢复示例”
  2. 按钮会变为“再次确认”
  3. 在 3 秒内再次点击

内置示例参数如下：

项目示例值
目前股数600 股
目前成本HK$94.00 / 股
目前股价HK$49.00 / 股
每手股数100 股
买入计划100 股 × HK$49.00
买入费用HK$18.50
卖出计划100 股 × HK$60.00
卖出费用HK$18.50
目标成本HK$90.00 / 股

第三步：核对示例结果

恢复示例后，应看到接近以下结果：

结果预期值
资金回本成本HK$92.23 / 股
本次买卖净现金流净收回 HK$1,063.00
交易后持仓600 股
需要收回的总成本HK$55,337.00
按目前股价的总体盈亏−HK$25,937.00
目前股价距回本+88.22%
卖出后回本成本HK$100.84 / 股

出现几分钱的显示差异时，应先确认输入的小数位和费用设置是否一致。

第四步：改变买入或卖出价格

可以使用两种方式修改价格：

  • 拖动价格滑杆，快速观察结果变化
  • 直接在价格框输入精确值

建议分别尝试：

  1. 降低买入价格，观察新回本成本是否下降
  2. 提高卖出价格，观察卖出后成本与净现金流变化
  3. 将某一侧交易股数改为 0，确认该侧手续费不会计入

第五步：试用目标成本反推

在“目标成本反推”中输入目标价格，例如 90。

系统会显示：

  • 理论需要买入的股数
  • 按每手股数向上取整后的最少手数
  • 对应预计投入
  • 应用该方案后的实际新成本

点击“应用方案”后，建议的整手股数会写入买入计划，并触发整页重新计算。

当买入价格不低于目标成本时，继续买入只能让成本逐渐接近买入价，无法摊薄到更低的目标，页面会给出相应提示。

第六步：比较 1 至 5 手方案

在“1 至 5 手买入方案”表格中，可以查看每个方案的：

  • 买入手数
  • 对应股数
  • 总投入
  • 新回本成本

点击某一行的应用按钮，即可把该方案写入买入股数。

5. 完整操作方法

5.1 填写持仓基准

  1. 输入股票代码和名称
  2. 输入目前股数
  3. 输入目前每股成本
  4. 输入目前股价
  5. 确认每手股数

注意：

  • 目前股数必须大于 0
  • 股数和每手股数必须填写整数
  • 每手股数请按照具体证券的交易单位填写
  • 目前股价不会改变回本成本本身，但会影响总体盈亏和回本距离

5.2 填写买入计划

依次填写：

  • 买入价格
  • 买入股数
  • 买入费用

买入费用会计入本次买入总支出，从而影响资金回本成本。

如果没有买入计划，请将买入股数设为 0。此时即使费用框保留了数值，该侧费用也不会计入结果。

5.3 填写卖出计划

依次填写：

  • 卖出价格
  • 卖出股数
  • 卖出费用

卖出净所得的计算方式为：

卖出净所得 = 卖出股数 × 卖出价格 − 卖出费用

如果没有卖出计划，请将卖出股数设为 0。卖出股数不能超过目前持仓。

5.4 理解净现金流

净现金流 = 卖出净所得 − 买入总支出
  • 显示“净收回”表示本次计划整体有现金流入
  • 显示“净投入”表示本次计划整体需要追加资金

净现金流只描述本次计划的资金进出，不代表整笔持仓已经盈利。

6. 交易费用设置

点击交易参数区顶部的“费用：手动”或“费用：自动”按钮，打开费用设置。

6.1 手动填写

适合已经从券商预估单或历史成交单中获得较准确费用的情况。

操作方法：

  1. 选择“手动填写”
  2. 点击“应用设置”
  3. 在买入费用和卖出费用框中填写预计金额

6.2 自动估算

自动模式可设置：

  • 证券类型：普通港股、印花税豁免或自定义
  • 券商佣金率
  • 每笔最低佣金
  • 是否计入股票印花税
  • 是否计入交收费估算

页面还会展示买入和卖出费用预估。完成设置后，点击“应用设置”。

注意：

  • 自动费用按每一侧作为一笔订单估算
  • 1 至 5 手方案表中的每个方案均按一笔买单计费
  • 不同券商、证券类型和成交方式可能采用不同收费标准
  • ETF 等证券是否豁免印花税，应以实际证券和成交单为准
  • 自动费用只用于快速测算，不应代替券商最终费用

7. 结果解读

7.1 资金回本成本

计算公式为：

资金回本成本 =
[
  原持仓股数 × 目前成本
  −（卖出股数 × 卖出价格 − 卖出费用）
  +（买入股数 × 买入价格 + 买入费用）
]
÷ 交易后持仓股数

其中：

交易后持仓股数 = 目前股数 − 卖出股数 + 买入股数

7.2 回本成本演变

  • 交易前：目前持仓成本
  • 卖出后：将卖出净所得冲减待收回资金后，剩余持仓对应的回本成本
  • 买入后：再加入买入总支出后的最终回本成本

卖出后成本上升并不一定表示计算错误。低于原成本卖出时，已经实现的亏损需要由剩余持仓继续收回，因此剩余持仓的资金回本成本可能升高。

7.3 总体盈亏

总体盈亏按照目前股价估算：

总体盈亏 = 交易后持仓股数 × 目前股价 − 需要收回的总成本

该数值用于模拟计划交易完成后的持仓状态，不是实际成交盈亏确认。

7.4 回本距离

“目前股价距回本”表示目前股价还需要上涨或下跌多少百分比，才能达到资金回本成本。

8. 保存方案 A / B

当需要比较两种操作计划时：

  1. 设置第一组买卖参数
  2. 点击顶部“本股方案”
  3. 在方案 A 中点击“保存当前”
  4. 返回页面，修改买卖价格、股数或费用
  5. 再次打开“本股方案”
  6. 在方案 B 中点击“保存当前”

保存两组方案后，页面会比较：

  • 回本成本差异
  • 净资金流差异
  • 交易后持仓
  • 交易费用

可以点击“载入”恢复某一组完整参数，也可以点击“清除”删除该方案。

每只已保存持仓拥有自己独立的方案 A / B，切换股票时不会与其他持仓混用。

9. 使用持仓簿管理多只股票

9.1 保存当前股票

  1. 至少填写股票代码或股票名称
  2. 完成交易参数设置
  3. 点击交易参数区顶部的“保存当前”

保存后，持仓簿会记录：

  • 股票代码和名称
  • 目前持仓
  • 目前成本
  • 当前股价
  • 当前资金回本成本
  • 最近更新时间
  • 本股方案与费用设置

9.2 开始下一只股票

点击顶部“新建测算”。如果当前内容存在未保存修改，系统会提供：

  • 保存并新建：先保存当前数据，再打开空白测算
  • 不保存，直接新建：放弃当前修改并清空页面
  • 取消：返回当前测算

新建测算会清空股票和交易参数，同时保留费用模式偏好与默认每手股数。

9.3 继续以前的测算

  1. 点击顶部“持仓簿”
  2. 找到需要继续的股票
  3. 点击“继续测算”

如需删除记录，第一次点击“删除”后按钮会变为确认状态，再次确认才会删除。

10. 换电脑继续使用

持仓、方案和费用设置默认只保存在当前浏览器。换电脑时建议使用 JSON 备份迁移。

10.1 在原电脑导出

  1. 打开“持仓簿”
  2. 点击“导出备份”
  3. 保存浏览器下载的 JSON 文件
  4. 通过可信方式把文件传到另一台电脑

10.2 在新电脑导入

  1. 在新电脑打开 costbuddy
  2. 打开“持仓簿”
  3. 点击“导入备份”
  4. 选择之前导出的 JSON 文件
  5. 查看导入摘要
  6. 点击“确认导入并替换”
导入会替换新电脑当前浏览器中的持仓簿、当前测算、方案和费用设置。导入前如已有重要数据，请先导出备份。

11. 复制与分享

11.1 复制结果

点击“复制结果”，系统会把当前股票信息、交易参数和主要测算结果复制到剪贴板，适合粘贴到备忘录或聊天工具中。

11.2 分享方案

点击“分享”，系统会复制一个带有当前参数的网页链接。接收者打开后，可以还原：

  • 股票信息
  • 持仓参数
  • 买卖计划
  • 目标成本
  • 费用模式和费用设置

分享链接不包含登录账户或身份信息，但会包含当前股票和交易参数。发送前请确认这些参数可以被接收者查看。

13. 建议试用检查清单

完成一次试用后，可以按以下项目检查：

  • □输入参数后，结果是否能实时更新
  • □买入和卖出价格滑杆是否容易使用
  • □回本成本演变是否容易理解
  • □资金明细是否能解释最终结果
  • □目标成本反推是否符合预期
  • □1 至 5 手方案是否便于比较
  • □方案 A / B 是否可以正确保存和载入
  • □持仓簿是否能保存并恢复多只股票
  • □页面刷新后，本地输入是否仍然保留
  • □JSON 备份能否成功导出和导入
  • □复制结果和分享链接是否正常
  • □当前窗口尺寸下，三列布局和分界线是否完整显示

反馈问题时，建议同时记录：浏览器名称、窗口尺寸、输入参数、费用模式、预期结果和实际结果。请避免公开真实账户、成交单号或其他敏感信息。

14. 数据与隐私

  • 所有计算均在浏览器本地完成
  • 持仓簿、方案和输入默认保存在当前浏览器的 LocalStorage 中
  • 本地数据不会自动上传到 costbuddy 服务器
  • 清除浏览器数据、使用隐私窗口或更换浏览器，可能导致记录无法继续读取
  • 建议定期导出 JSON 备份

15. 免责声明

结果仅用于持仓测算，不构成投资建议；暂不包含汇率及其他费用。自动费用仅为估算，应以交易所、监管机构及实际券商成交单为准。使用者应自行核对输入数据、证券交易单位和费用标准，并独立判断交易风险。
