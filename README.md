# 小算盘（costbuddy）

一个轻巧、可爱、纯前端且无需安装依赖的港股持仓资金回本成本测算工具。直接打开 `index.html` 即可使用，也适合部署到 GitHub Pages。

## 核心功能

- 计算交易前、卖出后、买入后的资金回本成本
- 支持填写股票代码和股票名称，纯数字代码自动补足为 5 位
- 支持买卖价格滑杆与精确输入
- 支持手动填写交易费用
- 支持按成交金额自动估算交易费用
- 自动费用可设置券商佣金率、最低佣金、股票印花税及交收费
- 提供普通港股、印花税豁免和自定义三种证券类型费用预设
- 股数为 0 时不计入该侧费用
- 按目标回本成本反推理论买入股数和最少整手方案
- 比较 1 至 5 手买入方案
- 展示交易后持仓、需要收回的资金、总体盈亏、回本距离和净现金流
- 对负回本成本、零股价、非整手交易等特殊结果给出单行解释
- 一键复制完整测算结果
- 使用“持仓簿”保存多只股票的当前测算进度，并随时继续测算
- 一键新建空白测算；切换或新建前会提示保存未提交修改
- 每条持仓独立保存方案 A / B，对比回本成本、净资金流、交易后持仓和费用
- 生成包含当前参数与费用模式的分享链接
- 自动保存上次输入、当前持仓关联和本地方案，并可恢复默认示例
- “恢复示例”采用 3 秒内二次确认，减少误触覆盖输入

## 成本口径

本工具计算的是“资金回本成本”：

```text
资金回本成本 =
[原持仓股数 × 目前成本
 - (卖出股数 × 卖出价格 - 卖出费用)
 + (买入股数 × 买入价格 + 买入费用)]
÷ 交易后持仓股数
```

卖出净所得会冲减仍需收回的资金，因此该结果包含已实现卖出盈亏的影响，可能不同于券商按成交批次显示的账面平均成本。

## 自动费用模式

自动费用模式包含以下可配置或估算项目：

- 券商佣金率和每笔最低佣金
- 股票印花税（可关闭，适配豁免证券）
- 证监会交易征费
- 会财局交易征费
- 交易费
- 交收费估算（可关闭）

自动模式仅用于快速估算。ETF、印花税豁免证券及不同券商的收费规则可能不同，应以实际成交单为准。

## 持仓簿、方案与分享

- “保存当前”会把股票信息、交易参数、费用设置和本股方案保存为一条持仓记录
- “持仓簿”可管理多只股票；每条记录显示目前持仓、目前成本、当前股价、资金回本成本和更新时间
- “新建测算”会清空当前股票和交易参数，但保留费用计算偏好与每手股数默认值
- 新建或切换持仓前若存在未保存修改，可选择“保存并继续”“不保存继续”或取消
- 每条持仓拥有独立的方案 A / B，切换股票时不会串用其他股票的方案
- 两组方案会比较回本成本和净资金流差异；点击“载入”可恢复整组参数
- “分享”会生成带参数的页面链接，接收者打开后可还原股票信息、交易参数和费用预设
- 持仓、输入和方案默认只保存在当前浏览器；分享链接本身会包含测算参数，请按需发送

## 默认示例

- 目前持仓：600 股
- 目前成本：HK$94.00 / 股
- 买入：100 股，HK$49.00
- 卖出：100 股，HK$60.00
- 手动买入费用：HK$18.50
- 手动卖出费用：HK$18.50
- 交易后持仓：600 股
- 资金回本成本：HK$92.23 / 股
- 本次买卖净现金流：净收回 HK$1,063.00

## 界面设计

- 面向桌面和笔记本的一屏工作台
- 页面不产生横向或纵向滚动
- 所有模块使用统一透明背景，通过边框和留白划分结构
- 买入使用蓝色提示，卖出使用橙色提示
- 输入、结果、目标方案、图表和资金明细同时显示
- 多股票记录收纳在弹窗式持仓簿中，不占用主工作台空间

## 本地使用

直接双击打开：

```text
index.html
```

也可以启动任意静态文件服务器：

```bash
python3 -m http.server 8765
```

然后访问 `http://localhost:8765/`。
