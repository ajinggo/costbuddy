## 项目简介

**costbuddy（小算盘）** 是一个面向港股持仓场景的资金回本成本测算工具。

输入目前持仓、成本、买卖计划与交易费用后，可以直观看到卖出后的剩余资金成本、继续买入后的新回本成本、资金流变化，以及达到目标成本所需的理论股数和整手方案。

> costbuddy 计算的是包含已实现卖出盈亏影响的“资金回本成本”，不等同于券商按成交批次展示的账面平均成本。

## 核心能力

### 交易与成本测算

- 计算交易前、卖出后与买入后的资金回本成本
- 展示交易后持仓、待收回资金、总体盈亏、回本距离与净现金流
- 支持买卖价格滑杆和精确数值输入
- 股数为 `0` 时，不计入该侧手续费
- 对负回本成本、清仓、零股价和非整手交易等特殊结果给出提示

### 费用估算

- 支持手动录入买入与卖出费用
- 支持按成交金额自动估算费用
- 可设置券商佣金率、最低佣金、印花税与交收费
- 内置普通港股、印花税豁免证券与自定义费用预设

### 目标成本与方案比较

- 根据目标回本成本反推理论买入股数
- 自动换算满足目标的最少整手方案
- 对比 `1–5` 手买入方案的投入金额与新回本成本
- 保存本股方案 A / B，对比回本成本、净资金流、持仓和费用差异

### 持仓与数据管理

- 使用“持仓簿”保存多只股票的当前测算进度
- 新建空白测算后，可继续计算下一只股票
- 支持导出和导入 JSON 备份，方便在另一台设备继续使用
- 支持生成包含当前测算参数的分享链接
- 自动保存当前输入、费用偏好与方案

## 成本口径

资金回本成本的计算逻辑为：

```text
资金回本成本 =
[
  原持仓股数 × 目前成本
  -（卖出股数 × 卖出价格 - 卖出费用）
  +（买入股数 × 买入价格 + 买入费用）
]
÷ 交易后持仓股数
```

其中：

```text
交易后持仓股数 = 原持仓股数 - 卖出股数 + 买入股数
```

卖出净所得会冲减仍需从剩余持仓中收回的资金，因此：

- 盈利卖出可能降低后续资金回本成本
- 亏损卖出可能提高后续资金回本成本
- 卖出净所得高于剩余待回收资金时，结果可能为负数
- 结果可能与券商 App 中显示的账面平均成本不同

## 界面设计

- 面向桌面与笔记本的一屏工作台
- 输入区、核心结果区和行动工具区采用三列结构
- 页面随窗口尺寸自动适配，分界线限制在工作区内
- 买入使用蓝色提示，卖出使用橙色提示
- 各模块以留白和细分隔线组织，不使用独立大色块背景
- 交易参数、成本路径、目标方案、手数矩阵、市场曲线与资金明细同时可见
- 持仓簿、费用设置与方案对比收纳在弹窗中，不占用主工作台空间

## 隐私说明

costbuddy 是纯前端静态应用，计算直接在浏览器中完成：

- 输入、持仓簿、方案和费用设置默认保存在当前浏览器的本地存储中
- 本地数据不会自动上传到 costbuddy 或第三方服务器
- 导出备份由浏览器直接生成并保存到用户设备
- 分享链接会包含当前测算参数，请仅在需要时发送给他人
- 清除浏览器网站数据可能同时删除未导出的本地记录

## 本地运行

项目不依赖构建工具或第三方运行时，下载后可以直接打开 `index.html`。

为了获得与线上环境一致的访问方式，也可以在项目目录启动静态服务器：

```bash
python3 -m http.server 8765
```

然后访问：

```text
http://localhost:8765/
```

## 部署

### Vercel

正式网站部署在 Vercel，并绑定自定义域名 `costbuddy.space`。

GitHub 仓库的 `main` 分支已连接 Vercel。更新并推送到 `main` 后，Vercel 会自动触发生产部署。

### GitHub Pages

GitHub Pages 使用 `main` 分支根目录发布，作为静态备用入口。项目全部由 HTML、CSS 和 JavaScript 组成，无需额外构建命令。
